# 🌸 Moon Flowers – Online Flower Shop
Hy I am Priyanka Mondkar,
Moon Flowers is a modern and responsive online flower shop website that allows users to browse, select, and purchase beautiful flower arrangements for different occasions.

## 🚀 Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** MySQL  

---

## ✨ Features

### 👤 User Side
- Browse all flower products
- View product details
- Add to cart
- Buy Now / Checkout functionality
- User authentication (Login / Signup)
- Order history

### 🛠️ Admin Panel
- Admin login
- Add / Update / Delete products
- Manage orders
- View users
